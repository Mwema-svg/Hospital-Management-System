# Hospital Patient Management System

A desktop-based Hospital Patient Management System developed using **VB.NET Windows Forms** and **Microsoft SQL Server**. The application helps manage essential hospital operations through a simple and user-friendly interface.

## Features

- **Authentication:** Secure login and administrator account creation.
- **Dashboard:** Central navigation for hospital operations.
- **Patient Management:** Register, view, update, search, and delete patient records.
- **Doctor Management:** Manage doctor information and specializations.
- **Department Management:** Create, update, search, and manage hospital departments and department heads.
- **Database Integration:** Store and retrieve records using Microsoft SQL Server.

## Technologies Used

- VB.NET
- Windows Forms
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Microsoft.Data.SqlClient
- Visual Studio
- .NET 10

## Database Setup

1. Install Microsoft SQL Server.
2. Create a database named `HospitalManagement`.
3. Create the required tables: `Users`, `Patients`, `Doctors`, and `Departments`.
4. Configure the database connection in `DbConnection.vb`.
5. Run the application through Visual Studio.

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/Mwema-svg/Hospital-Management-System.git
   ```

2. Open the solution file in Visual Studio.
3. Restore the required NuGet packages.
4. Configure your SQL Server connection.
5. Build and run the application.
